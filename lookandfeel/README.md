# Plasma Look and Feel

This is the `org.lnp.desktop` Plasma theme package. It provides LNP's colours,
icons, cursors, and starting panel layout.

Some KDE settings do not work reliably when placed in a theme. Those settings
live in `../defaults/`. Touchpad settings depend on the device, so `../apply/`
handles them after sign-in.

See `org.lnp.desktop/README.md` for the files in the theme. Installation paths
are listed in `../specs/lnp.spec`.
